## Load harness

`backend/ticketing-platform/scripts/waitlist-undo-load.py` uses Python's standard library. Start the ticketing service against a seeded PostgreSQL database. Prepare a local JSON file with at least 150 records shaped like `{"entryId":"...","token":"..."}`; use distinct owners and eligible cancelled entries for `unique`, or repeat one entry ID and its owner's token for `contention`. Keep the file outside Git because it contains bearer tokens. Run the command from `backend/ticketing-platform`.

```powershell
python .\scripts\waitlist-undo-load.py --base-url http://localhost:8091 --cases .\waitlist-undo-cases.local.json --scenario unique
python .\scripts\waitlist-undo-load.py --base-url http://localhost:8091 --cases .\waitlist-undo-contention.local.json --scenario contention
```

Each run releases 150 requests together. It reports status counts and p95; success requires p95 <= 4.0 seconds plus 150 successful independent undos, or exactly one success and 149 conflicts in the contention scenario. No live load result is claimed in this submission.

# EventHub artwork

`concert.jpg` is a bundled illustration for authentication and the personal profile header. It is not used as a substitute for an event's actual banner. Event cards show the backend banner, or an explicit placeholder when none is provided.

Download source: https://images.unsplash.com/photo-1493225457124-a3eb161ffa5f?w=1200&q=85&fit=crop

The EventHub mark, icons, envelope and lock illustrations are editable React Native SVG components in `src/components/`.
